# SwaraCoach

**Sing in tune. See your voice.** An iOS app that helps amateur singers improve their pitch: it listens through the microphone, shows your voice live against the target melody, scores accuracy fairly (only when you are actually singing) and tracks your progress.

SE4041 Mobile Application Design & Development — Assignment 02, Part A.

## Features
- Onboarding with microphone permission and headphone advice
- Library of public-domain songs and exercises (including the *Sa Re Ga Ma* swara scale)
- Real-time pitch detection (YIN algorithm, Accelerate/vDSP)
- Live scrolling pitch graph (SwiftUI `Canvas`) with a synthesised guide tone
- **On-device sound classification (SoundAnalysis / Core ML)**: only singing is scored; talking and noise are ignored and explained with hints
- Scoring in cents (octave tolerant), stars, personal best, animated results
- Tuner with a custom spring-animated gauge
- Voice-range test (bass … soprano)
- Progress: streak, weekly average, Swift Charts history (pinch to zoom), swipe to delete
- SwiftData persistence · Dark Mode · Dynamic Type · VoiceOver labels · Reduce Motion · iPad layouts

## Build & run
1. `git clone <repo-url>` and open `SwaraCoach.xcodeproj` in Xcode
2. Choose an iPhone simulator (or your iPhone) and press **Cmd+R**
3. Run all tests with **Cmd+U** (unit tests + UI tests; UI tests use a simulated singer, no microphone needed)
4. If `SwaraCoach.xcodeproj` is missing: install XcodeGen (`brew install xcodegen`) and run `xcodegen generate`, or follow `Docs/LAB_CHECKLIST.md` Appendix A.

Use **headphones**: otherwise the guide tone leaks into the microphone and is scored instead of your voice.

## Project structure
```
SwaraCoach/
  App/          app entry point, tab/root navigation
  Core/         pure logic: Note, Melody, PitchDetector (YIN), PitchSmoother, ScoreCalculator, VoiceRange
  Audio/        microphone input, SoundAnalysis classifier, guide-tone synth, simulated input for tests
  Models/       SwiftData models (PracticeSession, VoiceProfile)
  ViewModels/   @Observable view models (session, tuner, range test)
  Views/        screens (Onboarding, Library, Session, Tuner, Progress)
  Components/   reusable UI: PitchGraphView, TunerGaugeView, ScoreRingView, StarRatingView, GlowCard modifier, Theme
SwaraCoachTests/    XCTest unit tests (synthetic sine waves, scoring, persistence)
SwaraCoachUITests/  XCUITest UI tests (simulated audio)
Docs/           user guide, technical documentation, report, UAT, classifier evaluation, viva notes
```
